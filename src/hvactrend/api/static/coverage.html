POINT COVERAGE

Every monitoring rule needs certain points: the discharge-air rule needs the discharge temperature and its setpoint, the static rule the duct static and its setpoint, and so on. For each unit, a rule is ready when everything it needs is logged, needs logging when the controller has the point but it is not logged, missing when the unit has no such point, and not possible when the site knowledge says it cannot work on that unit.
Points that are not what their name says are set aside, never offered, and listed with the reason: the ones you ruled out (kept in site_knowledge in config/config.yaml), and the ones whose own controller reports them unreliable (checked live each time this page opens). Start logging is a change to this program only; nothing is written to a controller.
